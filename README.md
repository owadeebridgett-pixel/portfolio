# Bridgett's Automation Studio — Portfolio Website

Portfolio and case study website for Bridgett's Automation Studio, a Business Operating Systems consultancy based in the Western Cape, South Africa.

---

## About

This site positions Bridgett's Automation Studio as a Business Operating Systems consultancy — designing connected business infrastructure on monday.com for South African SMEs across recruitment, accounting, real estate, professional services, legal, HR and operations.

The site is built as a collection of standalone HTML pages — no frameworks, no dependencies, no build process. Each file works independently and links to the others normally.

No frameworks. No npm. No build pipeline. Open any file in a browser and it works.

## Hosting

Hosted on GitHub Pages.

To enable: **Settings → Pages → Branch: main → Save**

Live at: `https://yourusername.github.io/your-repo-name`

## Enquiries

All strategy call requests go to a monday.com form. The "Book a Strategy Call" button across the site links to:

`https://forms.monday.com/forms/eec3bcc41078bef6a2ad21260fce70c8?r=euc1`

Submissions land in the Website Enquiries board on monday.com.

## Editing Content

All content lives in the HTML files. To update anything:

1. Go to the file in GitHub
2. Click the pencil icon to edit
3. Make your changes
4. Click **Commit changes**

The site updates within 2 minutes.

**Quick reference — where things live:**

| What to change | Where to find it |
|---|---|
| Hero headline | `index.html` — search `hero-h1` |
| Case study copy | `casestudy.html` |
| Insight articles | `insight-1.html` through `insight-6.html` |
| Contact details | `contact.html` |
| Navigation labels | Every file — search `nav-links` |
| monday.com form link | Every file — search `forms.monday.com` |
